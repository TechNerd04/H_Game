# Horuf Hex Game

A real-time multiplayer hexagon-based trivia game.

## Features
- Interactive 5x5 Hexagon Board
- Real-time multiplayer synchronization via Socket.io
- Dynamic alphabet-based trivia database

## Installation

### Frontend (Client)
```bash
cd client
npm install
npm run dev
```

### Backend (Server)
```bash
cd server
npm install
node index.js
```
